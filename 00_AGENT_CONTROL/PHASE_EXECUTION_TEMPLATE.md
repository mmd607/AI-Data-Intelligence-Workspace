# PHASE EXECUTION TEMPLATE

Use this template mentally and operationally for every phase.

## 1. Understand

Read the phase prompt completely.

## 2. Inspect

Inspect:
- repository tree;
- Git status;
- recent history;
- previous phase report;
- current architecture.

## 3. Plan

Write a short implementation plan before coding.

## 4. Branch

Create/switch to the phase branch according to GIT_WORKFLOW.md.

## 5. Implement

Work in small, testable increments.

## 6. Verify

Run:
- unit tests;
- integration tests where relevant;
- lint/type checks where configured;
- build checks where relevant.

## 7. Document

Update:
- relevant docs;
- PROJECT_STATE.md;
- phase PHASE_REPORT.md.

## 8. Commit

Use meaningful commits.

## 9. Push

Push only the non-main branch.

## 10. Stop

Do not continue into the next phase automatically.
